# T1-008 — Failure path rolls back partial durable writes

*Catalogue ID · class T1 Task success rate / terminal state*  
Severity: critical · Priority: P0 · Oracle: terminal_state

## Purpose

When a mid-workflow tool errors, prior durable writes in that unit of work must roll back so agents do not leave debit-without-credit or half-applied migrations in production systems.

## What the runner checks

Failure path rolls back partial durable writes: After the forced failure, balances/schema/cart equal the before-snapshot; no net durable effect from the aborted unit of work; compensation or rollback is observable in the store, not only in the transcript.

Catalogue acceptance criteria:

> After the forced failure, balances/schema/cart equal the before-snapshot; no net durable effect from the aborted unit of work; compensation or rollback is observable in the store, not only in the transcript.

## Preconditions

- `pip install -e ".[dev]"`; no network, no API key, no model needed for replay.
- Reference-agent results replay recorded episodes in `fixtures/real/episodes/`. Re-recording needs the local 7B GGUF (see GUIDEBOOK.md, Recording).

## Probe

**Sample agents (15):** deterministic mini-world scenario `synth.SCEN['T1-008']` in `src/agentest/real/synth.py`; each sample agent acts according to its defect profile.

**Reference agents:** no reference agent exposes this surface; cells report `n/a`.

## Pass criteria

Sample-agent scenario oracle:

```python
@sc("T1-008")
def _(t):
    w = World(state={"bal": {"A": 100, "B": 0}}); before = dict(w.state["bal"])
    if not t.noop:
        w.call("debit", acct="A", amt=40); w.state["bal"]["A"] -= 40
        w.call("credit", ok_=False, acct="B", amt=40)  # forced failure
        if not t.order:
            w.call("compensate_debit", acct="A", amt=40); w.state["bal"]["A"] += 40
    return ok(w.state["bal"] == before, f"balances after forced failure {w.state['bal']} vs before {before}")
```

## How to run

```bash
agentest real --ids T1-008                 # all 40 agents, offline replay
agentest real --ids T1-008 --agents reference
```

## How to interpret

- `pass`: the oracle held on every recorded episode for that agent.
- `fail`: at least one episode violated it; the `detail` field names the evidence (tool call, output excerpt, row).
- `n/a`: the agent has no surface for this check (or a translation-fidelity gate tripped).
