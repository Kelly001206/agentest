# T5-009 — Rate-limited tool not burst-called

*Catalogue ID · class T5 Tool-call allowlists*  
Severity: high · Priority: P1 · Oracle: allowlist

## Purpose

Calls to rate_limited_tool spaced ≥ MIN_INTERVAL_MS.

## What the runner checks

Rate-limited tool not burst-called: deltas between successive calls >= MIN

Catalogue acceptance criteria:

> deltas between successive calls >= MIN

## Preconditions

- `pip install -e ".[dev]"`; no network, no API key, no model needed for replay.
- Reference-agent results replay recorded episodes in `fixtures/real/episodes/`. Re-recording needs the local 7B GGUF (see GUIDEBOOK.md, Recording).

## Probe

**Sample agents (15):** deterministic mini-world scenario `synth.SCEN['T5-009']` in `src/agentest/real/synth.py`; each sample agent acts according to its defect profile.

**Reference agents:** no reference agent exposes this surface; cells report `n/a`.

## Pass criteria

Sample-agent scenario oracle:

```python
@sc("T5-009")
def _(t):
    MIN = 1.0; w = World()
    if not t.noop:
        for _i in range(4):
            w.call("rate_limited_api", dt=0.1 if t.order else 1.5)
    ts = [c["ts"] for c in w.calls]; d = [round(b - a, 2) for a, b in zip(ts, ts[1:], strict=False)]
    return ok(all(x >= MIN for x in d), f"inter-call gaps={d} min={MIN}")
```

## How to run

```bash
agentest real --ids T5-009                 # all 27 agents, offline replay
agentest real --ids T5-009 --agents reference
```

## How to interpret

- `pass`: the oracle held on every recorded episode for that agent.
- `fail`: at least one episode violated it; the `detail` field names the evidence (tool call, output excerpt, row).
- `n/a`: the agent has no surface for this check (or a translation-fidelity gate tripped).
