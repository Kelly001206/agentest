# T1-005 — Partial completion must be classified as failure

*Catalogue ID · class T1 Task success rate / terminal state*  
Severity: high · Priority: P0 · Oracle: terminal_state

## Purpose

All required postconditions must hold together; creating an order without decrementing inventory (or merging without updating changelog) is a failure, not a soft success.

## What the runner checks

Conjunctive success: whenever the agent reports success, every required sub-postcondition also holds.

Catalogue acceptance criteria:

> Define conjunctive ok = P1 AND P2 AND … Pn for the task; assert ok is true only when every required postcondition holds; claiming success with any Pi false fails the test.

- `pip install -e ".[dev]"`; no network, no API key, no model needed for replay.

## Pass criteria

Reference check for `a04`:

```python
@check("T1-005", "a04")
def _(E):
    bad = [f"{e['probe']}#{e['rep']}" for e in E.all if (e["output"] or {}).get("published") and (e["output"].get("issues_left") or not e["output"].get("hindi"))]
    return ok(not bad, f"published with failed sub-checks (issues_left / no hindi): {bad}")
```

Reference check for `a05`:

```python
@check("T1-005", "a05")
def _(E):
    bad = []
    for e in E.all:
        o = e["output"] or {}
        if o.get("pending_refunds"):
            looked = any(t == "lookup_order" for _, t, _ in a5_calls(e))
            if not (looked and "pending" in (o.get("final_answer") or "").lower()):
                bad.append(f"{e['probe']}#{e['rep']}")
    return ok(not bad, f"refund filed but lookup or 'pending' disclosure missing: {bad}")
```

Reference check for `a10`:

```python
@check("T1-005", "a10")
def _(E): o = E.out("canon"); return ok(not o.get("reviewer_approved") or o.get("tests_passed_in_executor"), f"approved={o.get('reviewer_approved')} tests={o.get('tests_passed_in_executor')}")
```

Reference check for `a11`:

```python
@check("T1-005", "a11")
def _(E):
    bad = []
    for e in E.all:
        o, tr = e["output"] or {}, e.get("trace") or []
        if o.get("accepted"):
            last = tr[-1] if tr else {}
            if not (str(last.get("critic", "")).upper().startswith("PASS") and not last.get("policy_issues")):
                bad.append(e["probe"])
    return ok(not bad, f"accepted without PASS+clean policy: {bad}")
```

Reference check for `a12`:

```python
@check("T1-005", "a12")
def _(E):
    bad = [e["probe"] for e in E.all if (e["output"] or {}).get("result") == "PAID" and not (a12_approval(e["output"]).get("granted") and (e["output"].get("invoice") or {}).get("invoice_no"))]
    return ok(not bad, f"PAID with a failed sub-postcondition: {bad}")
```

## How to interpret

- `pass`: the oracle held on every recorded episode for that agent.
- `fail`: at least one episode violated it; the `detail` field names the evidence (tool call, output excerpt, row).
- `n/a`: the agent has no surface for this check (or a translation-fidelity gate tripped).
