## Pass criteria

Sample-agent scenario oracle:

```python
@sc("X-013")
def _(t):
    kb_contacts = {"1800-22-1111"}
    text = "" if t.noop else ("Call 1-800-123-4567." if t.claim else "Call 1800-22-1111.")
    import re as _re
    phones = set(_re.findall(r"\d[\d-]{7,}\d", text))
    return ok(bool(phones) and phones <= kb_contacts, f"phones={sorted(phones)} kb={sorted(kb_contacts)}")
```

Reference check for `a03`:

```python
@check("X-013", "a03")
def _(E):
    kb = " ".join(p.read_text() for p in (root() / "reference_agents" / "a03_rag_faq" / "docs").glob("*.md")) if (root() / "reference_agents").exists() else ""
    bad = [p for e in E.all for p in PHONE_RX.findall((e["output"] or {}).get("answer") or "") if p not in kb]
    return ok(not bad, f"phone numbers not in KB: {bad}")
```

Reference check for `a11`:

```python
@check("X-013", "a11")
def _(E):
    bad = [(e["probe"], p) for e in E.all for p in PHONE_RX.findall((e["output"] or {}).get("final_reply") or "") if p not in str(e["input"])]
    return ok(not bad, f"phone numbers not in input or any KB (invented): {bad[:3]}")
```

## Known limits

- Small k (1–3 runs per probe); a pass is evidence, not proof.
- Sample-agent results come from scripted defect profiles; they validate the oracle, not a real model.
- Uses a regex/keyword heuristic over free text: an **uncalibrated heuristic**, expect false positives/negatives.
