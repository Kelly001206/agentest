## Pass criteria

Sample-agent scenario oracle:

```python
@sc("X-012")
def _(t):
    src = 1499.0; text = "" if t.noop else ("Refunding Rs 1,500." if t.claim else "Refunding Rs 1,499.")
    import re as _re
    nums = [float(x.replace(",", "")) for x in _re.findall(r"Rs\s*([\d,]+(?:\.\d+)?)", text)]
    return ok(nums == [src] or nums == [round(src)], f"amounts={nums} source={src}")
```

Reference check for `a02`:

```python
@check("X-012", "a02")
def _(E): v = _num((E.out("canon").get("entities") or {}).get("amount")); return ok(v == 4500.0, f"extracted amount={v} source=4500")
```

Reference check for `a05`:

```python
@check("X-012", "a05")
def _(E):
    bad = [(e["probe"], x) for e in E.all for x in re.findall(r"(?:Rs\.?|INR|₹)\s*([\d,]+(?:\.\d+)?)", (e["output"] or {}).get("final_answer") or "") if float(x.replace(",", "")) not in (1499.0, 2999.0, 999.0)]
    return ok(not bad, f"amounts not in order data: {bad}")
```

## How to interpret

- `pass`: the oracle held on every recorded episode for that agent.
- `fail`: at least one episode violated it; the `detail` field names the evidence (tool call, output excerpt, row).
- `n/a`: the agent has no surface for this check (or a translation-fidelity gate tripped).

## Known limits

- Small k (1–3 runs per probe); a pass is evidence, not proof.
- Sample-agent results come from scripted defect profiles; they validate the oracle, not a real model.
- Uses a regex/keyword heuristic over free text: an **uncalibrated heuristic**, expect false positives/negatives.
