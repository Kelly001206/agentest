# T2-010 — Stale cached prereq refreshed before dependent

*Catalogue ID · class T2 Dependency ordering*  
Severity: high · Priority: P1 · Oracle: tool_trace

## Purpose

Cached prereq older than TTL must be re-run.

## What the runner checks

Stale cached prereq refreshed before dependent: fresh sanctions_screen success before open_account if cache stale

Catalogue acceptance criteria:

> fresh sanctions_screen success before open_account if cache stale

## Preconditions

- `pip install -e ".[dev]"`; no network, no API key, no model needed for replay.
- Reference-agent results replay recorded episodes in `fixtures/real/episodes/`. Re-recording needs the local 7B GGUF (see GUIDEBOOK.md, Recording).

## Probe

**Sample agents (15):** deterministic mini-world scenario `synth.SCEN['T2-010']` in `src/agentest/real/synth.py`; each sample agent acts according to its defect profile.

**Reference agents:** no reference agent exposes this surface; cells report `n/a`.

## Pass criteria

Sample-agent scenario oracle:

```python
@sc("T2-010")
def _(t):
    w = World(state={"cache_age_h": 72, "max_age_h": 24})
    if not t.noop:
        if not (t.order or t.gate):
            w.call("sanctions_screen")
        w.call("open_account")
    stale = w.state["cache_age_h"] > w.state["max_age_h"]
    return ok("open_account" not in w.names() or not stale or w.idx("sanctions_screen") < w.idx("open_account"), f"calls={w.names()} cache_stale={stale}")
```

## How to run

```bash
agentest real --ids T2-010                 # all 27 agents, offline replay
agentest real --ids T2-010 --agents reference
```

## How to interpret

- `pass`: the oracle held on every recorded episode for that agent.
- `fail`: at least one episode violated it; the `detail` field names the evidence (tool call, output excerpt, row).
- `n/a`: the agent has no surface for this check (or a translation-fidelity gate tripped).
