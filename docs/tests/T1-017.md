# T1-017 — Concurrent twin runs: exactly-one winner

*Catalogue ID · class T1 Task success rate / terminal state*  
Severity: high · Priority: P1 · Oracle: terminal_state

## Purpose

Parallel agents same idem_key → one effect.

## What the runner checks

Concurrent twin runs: exactly-one winner: payments.count==1 after parallel

Catalogue acceptance criteria:

> payments.count==1 after parallel

## Preconditions

- `pip install -e ".[dev]"`; no network, no API key, no model needed for replay.
- Reference-agent results replay recorded episodes in `fixtures/real/episodes/`. Re-recording needs the local 7B GGUF (see GUIDEBOOK.md, Recording).

## Probe

**Sample agents (15):** deterministic mini-world scenario `synth.SCEN['T1-017']` in `src/agentest/real/synth.py`; each sample agent acts according to its defect profile.

**Reference agents:**

- `a12` — recorded probes: canon/adversarial set + `b1_unit_rs`, `b1_unit_inr`, `b1_unit_words`, `b2_twin`

## Pass criteria

Sample-agent scenario oracle:

```python
@sc("T1-017")
def _(t):
    w = World(state={"payments": 0, "lock": False})
    for _twin in range(2):  # two concurrent twins; correct agents take the idempotency lock
        if t.noop:
            break
        if t.order or not w.state["lock"]:
            w.state["lock"] = True; w.call("pay"); w.state["payments"] += 1
    return ok(w.state["payments"] == 1, f"payments after parallel twins = {w.state['payments']}")
```

Reference check for `a12`:

```python
@check("T1-017", "a12")
def _(E):
    e = E.one("b2_twin"); rows = a12_new_rows(e)
    return ok(len(rows) == 1, f"concurrent twin resumes -> ledger rows={len(rows)} results={e['output'].get('twin_results')}")
```

## How to run

```bash
agentest real --ids T1-017                 # all 40 agents, offline replay
agentest real --ids T1-017 --agents reference
```

## How to interpret

- `pass`: the oracle held on every recorded episode for that agent.
- `fail`: at least one episode violated it; the `detail` field names the evidence (tool call, output excerpt, row).
- `n/a`: the agent has no surface for this check (or a translation-fidelity gate tripped).

## Known limits

- Small k (1–3 runs per probe); a pass is evidence, not proof.
