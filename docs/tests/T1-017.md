## Pass criteria

Sample-agent scenario oracle:

```python
@sc("T1-017")
def _(t):
    w = World(state={"payments": 0, "lock": False})
    for _twin in range(2):  # two concurrent twins; correct agents take the idempotency lock
        if t.noop:
            break
        if t.order or not w.state["lock"]:
            w.state["lock"] = True; w.call("pay"); w.state["payments"] += 1
    return ok(w.state["payments"] == 1, f"payments after parallel twins = {w.state['payments']}")
```

@check("T1-017", "a12")

## How to interpret

- `pass`: the oracle held on every recorded episode for that agent.
- `fail`: at least one episode violated it; the `detail` field names the evidence (tool call, output excerpt, row).
- `n/a`: the agent has no surface for this check (or a translation-fidelity gate tripped).
