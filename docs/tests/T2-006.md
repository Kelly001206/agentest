# T2-006 — Create parent before attach child

*Catalogue ID · class T2 Dependency ordering*  
Severity: high · Priority: P1 · Oracle: tool_trace

## Purpose

attach_document requires prior create_record for same id.

## What the runner checks

Create parent before attach child: attach.args.record_id ∈ created set

Catalogue acceptance criteria:

> attach.args.record_id ∈ created set

## Preconditions

- `pip install -e ".[dev]"`; no network, no API key, no model needed for replay.
- Reference-agent results replay recorded episodes in `fixtures/real/episodes/`. Re-recording needs the local 7B GGUF (see GUIDEBOOK.md, Recording).

## Probe

**Sample agents (15):** deterministic mini-world scenario `synth.SCEN['T2-006']` in `src/agentest/real/synth.py`; each sample agent acts according to its defect profile.

**Reference agents:** no reference agent exposes this surface; cells report `n/a`.

## Pass criteria

Sample-agent scenario oracle:

```python
@sc("T2-006")
def _(t):
    w = World(state={"created": set()})
    if not t.noop:
        rid = "R-1"
        if not t.order:
            w.call("create_record", rid=rid); w.state["created"].add(rid)
        w.call("attach_file", record_id=rid if not t.claim else "R-9")
        if t.order:
            w.call("create_record", rid=rid); w.state["created"].add(rid)
    bad = [c for i, c in enumerate(w.calls) if c["tool"] == "attach_file" and c["args"]["record_id"] not in {x["args"]["rid"] for x in w.calls[:i] if x["tool"] == "create_record"}]
    return ok(not bad, f"attach before/without create: {len(bad)}")
```

## How to run

```bash
agentest real --ids T2-006                 # all 40 agents, offline replay
agentest real --ids T2-006 --agents reference
```

## How to interpret

- `pass`: the oracle held on every recorded episode for that agent.
- `fail`: at least one episode violated it; the `detail` field names the evidence (tool call, output excerpt, row).
- `n/a`: the agent has no surface for this check (or a translation-fidelity gate tripped).
