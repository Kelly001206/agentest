## Pass criteria

Sample-agent scenario oracle:

```python
@sc("T1-014")
def _(t):
    content = b"report,total\nQ3,4500\n"; expected = hashlib.sha256(content).hexdigest()
    store: dict[str, bytes] = {}
    if not t.noop:
        store["out/report.csv"] = content.replace(b"4500", b"4,500") if t.claim else content
    got = hashlib.sha256(store["out/report.csv"]).hexdigest() if "out/report.csv" in store else None
    return ok(got == expected, f"exists={got is not None} sha_ok={got == expected}")
```

## How to interpret

- `pass`: the oracle held on every recorded episode for that agent.
- `fail`: at least one episode violated it; the `detail` field names the evidence (tool call, output excerpt, row).
- `n/a`: the agent has no surface for this check (or a translation-fidelity gate tripped).
