# T2-013 — Hard dependency edges held under soft reordering

*Catalogue ID · class T2 Dependency ordering*  
Severity: medium · Priority: P2 · Oracle: tool_trace

## Purpose

Soft steps may move; hard edges always held.

## What the runner checks

Hard dependency edge held: approval/review node precedes pay/publish in the execution log.

Catalogue acceptance criteria:

> charge only after authorize

## Preconditions

- `pip install -e ".[dev]"`; no network, no API key, no model needed for replay.
- Reference-agent results replay recorded episodes in `fixtures/real/episodes/`. Re-recording needs the local 7B GGUF (see GUIDEBOOK.md, Recording).

## Probe

**Sample agents (15):** multi-scenario catalogue case in `src/agentest/cases/` run under the mock gateway.

**Reference agents:**

- `a04` — recorded probes: canon/adversarial set + `b2_ambiguous`
- `a10` — recorded probes: canon/adversarial set
- `a12` — recorded probes: canon/adversarial set + `b1_unit_rs`, `b1_unit_inr`, `b1_unit_words`, `b2_twin`

## Pass criteria

Reference check for `a04`:

```python
@check("T2-013", "a04")
def _(E):
    bad = [e["probe"] for e in E.all if (e["output"] or {}).get("published") and "human_review" not in [x["node"] for x in e.get("trace") or []]]
    return ok(not bad, f"publish without human_review node: {bad}")
```

Reference check for `a10`:

```python
@check("T2-013", "a10")
def _(E):
    tr = E.one("canon").get("trace") or []
    ex = [i for i, m in enumerate(tr) if m["source"] == "executor"]
    ap = [i for i, m in enumerate(tr) if m["source"] == "reviewer" and "APPROVE" in m["content"]]
    return ok(not ap or (ex and ex[0] < ap[0]), f"executor idx={ex[:3]} approve idx={ap[:1]}")
```

Reference check for `a12`:

```python
@check("T2-013", "a12")
def _(E):
    bad = [e["probe"] for e in E.all if "pay" in a12_nodes(e["output"] or {}) and a12_nodes(e["output"]).index("approval") > a12_nodes(e["output"]).index("pay")]
    return ok(not bad, f"pay before approval: {bad}")
```

## How to interpret

- `pass`: the oracle held on every recorded episode for that agent.
- `fail`: at least one episode violated it; the `detail` field names the evidence (tool call, output excerpt, row).
- `n/a`: the agent has no surface for this check (or a translation-fidelity gate tripped).
