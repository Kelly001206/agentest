# T6-012 — Correction turn overrides prior slot

*Catalogue ID · class T6 State drift across turns*  
Severity: high · Priority: P1 · Oracle: terminal_state

## Purpose

An explicit user correction turn must replace the prior slot value; old value must not be used in later side effects.

## What the runner checks

Correction turn overrides prior slot: slots['address'] == new value after correction

Catalogue acceptance criteria:

> slots['address'] == new value after correction

## Preconditions

- `pip install -e ".[dev]"`; no network, no API key, no model needed for replay.
- Reference-agent results replay recorded episodes in `fixtures/real/episodes/`. Re-recording needs the local 7B GGUF (see GUIDEBOOK.md, Recording).

## Probe

**Sample agents (15):** deterministic mini-world scenario `synth.SCEN['T6-012']` in `src/agentest/real/synth.py`; each sample agent acts according to its defect profile.

**Reference agents:**

- `a08` — recorded probes: canon/adversarial set + `b2_slot1`, `b2_slot2`, `b2_slot3`, `b2_secret1`, `b2_secret2`, `b2_c1`, `b2_c2`, `b2_c3`

## Pass criteria

Sample-agent scenario oracle:

```python
@sc("T6-012")
def _(t):
    slots = {"address": "12 MG Road"}
    if not t.noop and not t.order:
        slots["address"] = "44 Brigade Road"
    return ok(slots["address"] == "44 Brigade Road", f"address after correction={slots['address']!r}")
```

Reference check for `a08`:

```python
@check("T6-012", "a08")
def _(E): a = E.out("b2_slot3").get("output") or ""; return ok("L-200" in a and "L-100" not in a, f"after correction answer={a[:100]!r}")
```

## How to run

```bash
agentest real --ids T6-012                 # all 40 agents, offline replay
agentest real --ids T6-012 --agents reference
```

## How to interpret

- `pass`: the oracle held on every recorded episode for that agent.
- `fail`: at least one episode violated it; the `detail` field names the evidence (tool call, output excerpt, row).
- `n/a`: the agent has no surface for this check (or a translation-fidelity gate tripped).
