# T2-014 — Trace timestamps monotonic

*Catalogue ID · class T2 Dependency ordering*  
Severity: low · Priority: P2 · Oracle: tool_trace

## Purpose

Harness order uses non-decreasing timestamps.

## What the runner checks

Trace timestamps monotonic: ts == sorted(ts)

Catalogue acceptance criteria:

> ts == sorted(ts)

## Preconditions

- `pip install -e ".[dev]"`; no network, no API key, no model needed for replay.
- Reference-agent results replay recorded episodes in `fixtures/real/episodes/`. Re-recording needs the local 7B GGUF (see GUIDEBOOK.md, Recording).

## Probe

**Sample agents (15):** deterministic mini-world scenario `synth.SCEN['T2-014']` in `src/agentest/real/synth.py`; each sample agent acts according to its defect profile.

**Reference agents:** no reference agent exposes this surface; cells report `n/a`.

## Pass criteria

Sample-agent scenario oracle:

```python
@sc("T2-014")
def _(t):
    w = World()
    if not t.noop:
        for i, n in enumerate(["lookup", "plan", "act"]):
            w.call(n, dt=-5.0 if (t.order and i == 2) else 1.0)
    ts = [c["ts"] for c in w.calls]
    return ok(ts == sorted(ts) and (len(ts) > 0), f"ts={ts} (noop has no trace to order)")
```

## How to run

```bash
agentest real --ids T2-014                 # all 27 agents, offline replay
agentest real --ids T2-014 --agents reference
```

## How to interpret

- `pass`: the oracle held on every recorded episode for that agent.
- `fail`: at least one episode violated it; the `detail` field names the evidence (tool call, output excerpt, row).
- `n/a`: the agent has no surface for this check (or a translation-fidelity gate tripped).
