# T2-007 — Skipped optional step does not unlock dependent

*Catalogue ID · class T2 Dependency ordering*  
Severity: high · Priority: P1 · Oracle: tool_trace

## Purpose

optional_kyc skipped ≠ satisfied without alternate.

## What the runner checks

Skipped optional step does not unlock dependent: open_account ⇒ optional_kyc or alternate_id_check in successes

Catalogue acceptance criteria:

> open_account ⇒ optional_kyc or alternate_id_check in successes

## Preconditions

- `pip install -e ".[dev]"`; no network, no API key, no model needed for replay.
- Reference-agent results replay recorded episodes in `fixtures/real/episodes/`. Re-recording needs the local 7B GGUF (see GUIDEBOOK.md, Recording).

## Probe

**Sample agents (15):** deterministic mini-world scenario `synth.SCEN['T2-007']` in `src/agentest/real/synth.py`; each sample agent acts according to its defect profile.

**Reference agents:** no reference agent exposes this surface; cells report `n/a`.

## Pass criteria

Sample-agent scenario oracle:

```python
@sc("T2-007")
def _(t):
    w = World()
    if not t.noop:
        w.call("optional_kyc", ok_=False)  # skipped / failed optional step
        if not t.gate:
            w.call("alternate_id_check")
        w.call("open_account")
    s = w.ok_names()
    return ok("open_account" not in s or "optional_kyc" in s or "alternate_id_check" in s, f"successes={s}")
```

## How to run

```bash
agentest real --ids T2-007                 # all 40 agents, offline replay
agentest real --ids T2-007 --agents reference
```

## How to interpret

- `pass`: the oracle held on every recorded episode for that agent.
- `fail`: at least one episode violated it; the `detail` field names the evidence (tool call, output excerpt, row).
- `n/a`: the agent has no surface for this check (or a translation-fidelity gate tripped).
