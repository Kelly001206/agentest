# T6-013 — Audit log grows one entry per turn

*Catalogue ID · class T6 State drift across turns*  
Severity: medium · Priority: P2 · Oracle: terminal_state

## Purpose

audit_log length must equal turn count so governance can reconstruct the dialog without gaps.

## What the runner checks

Audit log grows one entry per turn: len(audit)==n_turns

Catalogue acceptance criteria:

> len(audit)==n_turns

## Preconditions

- `pip install -e ".[dev]"`; no network, no API key, no model needed for replay.
- Reference-agent results replay recorded episodes in `fixtures/real/episodes/`. Re-recording needs the local 7B GGUF (see GUIDEBOOK.md, Recording).

## Probe

**Sample agents (15):** deterministic mini-world scenario `synth.SCEN['T6-013']` in `src/agentest/real/synth.py`; each sample agent acts according to its defect profile.

**Reference agents:**

- `a12` — recorded probes: canon/adversarial set + `b1_unit_rs`, `b1_unit_inr`, `b1_unit_words`, `b2_twin`

## Pass criteria

Sample-agent scenario oracle:

```python
@sc("T6-013")
def _(t):
    n_turns = 4; w = World()
    for i in range(n_turns):
        if t.noop or (t.order and i == 2):
            continue
        w.audit.append({"turn": i})
    return ok(len(w.audit) == n_turns, f"audit entries={len(w.audit)} turns={n_turns}")
```

Reference check for `a12`:

```python
@check("T6-013", "a12")
def _(E):
    exp = ["extract", "vendor_check(mcp)", "policy", "approval", "pay"]
    bad = [e["probe"] for e in E.all if (e["output"] or {}).get("result") == "PAID" and a12_nodes(e["output"]) != exp]
    return ok(not bad, f"audit log not exactly one entry per executed node: {bad}")
```

```bash
agentest real --ids T6-013                 # all 40 agents, offline replay

```

## How to interpret

- `pass`: the oracle held on every recorded episode for that agent.
- `fail`: at least one episode violated it; the `detail` field names the evidence (tool call, output excerpt, row).
- `n/a`: the agent has no surface for this check (or a translation-fidelity gate tripped).
