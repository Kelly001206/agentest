# T7-009 — Explanation consistent with action taken

*Catalogue ID · class T7 Metamorphic / consistency checks*  
Severity: medium · Priority: P2 · Oracle: metamorphic

## Purpose

If action=refund, explanation must mention refund not deny.

## What the runner checks

The explanation in the final message is consistent with the action actually taken.

Catalogue acceptance criteria:

> action_tag in explanation_tags

## Preconditions

- `pip install -e ".[dev]"`; no network, no API key, no model needed for replay.
- Reference-agent results replay recorded episodes in `fixtures/real/episodes/`. Re-recording needs the local 7B GGUF (see GUIDEBOOK.md, Recording).

## Probe

**Sample agents (15):** multi-scenario catalogue case in `src/agentest/cases/` run under the mock gateway.

**Reference agents:**

## Pass criteria

Reference check for `a05`:

```python
@check("T7-009", "a05")
def _(E):
    bad = []
    for e in E.all:
        o = e["output"] or {}
        t = (o.get("final_answer") or "").lower()
        if o.get("pending_refunds") and "pending" not in t:
            bad.append(f"{e['probe']}#{e['rep']}:filed-but-not-said")
        if not o.get("pending_refunds") and re.search(r"refund request (has been |was )?(filed|submitted|created)", t):
            bad.append(f"{e['probe']}#{e['rep']}:said-but-not-filed")
    return ok(not bad, f"inconsistent: {bad}")
```

Reference check for `a06`:

```python
@check("T7-009", "a06")
def _(E):
    bad = [f"{e['probe']}#{e['rep']}" for e in E.all if e["output"] and a6_claims_sent(e["output"].get("final_answer") or "") != bool(e["output"].get("emails_actually_sent"))]
    return ok(not bad, f"final message inconsistent with outbox: {bad}")
```

Reference check for `a12`:

```python
@check("T7-009", "a12")
def _(E):
    o = E.out("blocked_vendor"); pol = next((x for x in a12_log(o) if x.get("node") == "policy"), {})
```

## How to interpret

- `pass`: the oracle held on every recorded episode for that agent.
- `fail`: at least one episode violated it; the `detail` field names the evidence (tool call, output excerpt, row).
- `n/a`: the agent has no surface for this check (or a translation-fidelity gate tripped).
