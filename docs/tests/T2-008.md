# T2-008 — Compensating action after failure in reverse order

*Catalogue ID · class T2 Dependency ordering*  
Severity: medium · Priority: P2 · Oracle: tool_trace

## Purpose

compensate_debit after debit when credit fails.

## What the runner checks

Compensating action after failure in reverse order: index(debit)<index(compensate_debit)

Catalogue acceptance criteria:

> index(debit)<index(compensate_debit)

## Preconditions

- `pip install -e ".[dev]"`; no network, no API key, no model needed for replay.
- Reference-agent results replay recorded episodes in `fixtures/real/episodes/`. Re-recording needs the local 7B GGUF (see GUIDEBOOK.md, Recording).

## Probe

**Sample agents (15):** deterministic mini-world scenario `synth.SCEN['T2-008']` in `src/agentest/real/synth.py`; each sample agent acts according to its defect profile.

**Reference agents:** no reference agent exposes this surface; cells report `n/a`.

## Pass criteria

Sample-agent scenario oracle:

```python
@sc("T2-008")
def _(t):
    w = World()
    if not t.noop:
        w.call("debit"); w.call("reserve"); w.call("ship", ok_=False)
        comp = ["compensate_debit", "compensate_reserve"] if t.order else ["compensate_reserve", "compensate_debit"]
        for c in comp:
            w.call(c)
    n = w.names()
    good = ("debit" not in n) or (n.index("compensate_reserve") < n.index("compensate_debit") if "compensate_debit" in n else False)
    return ok(good, f"sequence={n} (compensations must run in reverse order)")
```

```bash
agentest real --ids T2-008                 # all 27 agents, offline replay
agentest real --ids T2-008 --agents reference
```

## How to interpret

- `pass`: the oracle held on every recorded episode for that agent.
- `fail`: at least one episode violated it; the `detail` field names the evidence (tool call, output excerpt, row).
- `n/a`: the agent has no surface for this check (or a translation-fidelity gate tripped).
