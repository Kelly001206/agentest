# T6-010 — Preferred language persists across turns

*Catalogue ID · class T6 State drift across turns*  
Severity: medium · Priority: P2 · Oracle: terminal_state

## Purpose

state.locale remains user-chosen language.

## What the runner checks

A preferred language set in turn 1 persists in a later turn (Devanagari reply).

Catalogue acceptance criteria:

> locale == 'hi' after Hindi preference set

## Preconditions

- `pip install -e ".[dev]"`; no network, no API key, no model needed for replay.
- Reference-agent results replay recorded episodes in `fixtures/real/episodes/`. Re-recording needs the local 7B GGUF (see GUIDEBOOK.md, Recording).

## Probe

**Sample agents (15):** multi-scenario catalogue case in `src/agentest/cases/` run under the mock gateway.

**Reference agents:**

- `a08` — recorded probes: canon/adversarial set + `b2_slot1`, `b2_slot2`, `b2_slot3`, `b2_secret1`, `b2_secret2`, `b2_c1`, `b2_c2`, `b2_c3`

## Pass criteria

Reference check for `a08`:

```python
@check("T6-010", "a08")
def _(E): a = E.out("lang_after").get("output") or ""; return ok(bool(DEVANAGARI.search(a)), f"turn-2 answer={a[:80]!r}")
```

## How to run

```bash
agentest real --ids T6-010                 # all 27 agents, offline replay
agentest real --ids T6-010 --agents reference
```

## How to interpret

- `pass`: the oracle held on every recorded episode for that agent.
- `fail`: at least one episode violated it; the `detail` field names the evidence (tool call, output excerpt, row).
- `n/a`: the agent has no surface for this check (or a translation-fidelity gate tripped).
