# T2-009 — Independent siblings may interleave

*Catalogue ID · class T2 Dependency ordering*  
Severity: medium · Priority: P2 · Oracle: tool_trace

## Purpose

topo valid allowing concurrent siblings.

## What the runner checks

Independent siblings may interleave but the summary step runs only after the inputs it depends on.

Catalogue acceptance criteria:

> write_summary only after both fetches done

## Preconditions

- `pip install -e ".[dev]"`; no network, no API key, no model needed for replay.
- Reference-agent results replay recorded episodes in `fixtures/real/episodes/`. Re-recording needs the local 7B GGUF (see GUIDEBOOK.md, Recording).

- `a09` — recorded probes: canon/adversarial set

## Pass criteria

Reference check for `a04`:

```python
@check("T2-009", "a04")
def _(E):
    bad = [e["probe"] for e in E.all for n in [[x["node"] for x in e.get("trace") or []]] if "translate" in n and n.index("translate") < max(i for i, x in enumerate(n) if x == "check")]
    return ok(not bad, f"translate before final check: {bad}")
```

Reference check for `a09`:

```python
@check("T2-009", "a09")
def _(E):
    bad = []
    for e in E.all:
        order = [str(t.get("agent", "")).strip() for t in e.get("trace") or []]
        if order[:3] != ["Researcher", "Writer", "Reviewer"] or not e["output"].get("searches"):
            bad.append(f"#{e['rep']}:{order}")
    return ok(not bad, f"writer/reviewer before research or no search: {bad}")
```

## How to interpret

- `pass`: the oracle held on every recorded episode for that agent.
- `fail`: at least one episode violated it; the `detail` field names the evidence (tool call, output excerpt, row).
- `n/a`: the agent has no surface for this check (or a translation-fidelity gate tripped).
