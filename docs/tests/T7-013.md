# T7-013 — Multilingual user goal → same terminal state

*Catalogue ID · class T7 Metamorphic / consistency checks*  
Severity: high · Priority: P1 · Oracle: metamorphic

## Purpose

EN and HI instructions with same intent → same postconditions.

## What the runner checks

Multilingual user goal → same terminal state: postconditions(en_env)==True and postconditions(hi_env)==True

Catalogue acceptance criteria:

> postconditions(en_env)==True and postconditions(hi_env)==True

## Preconditions

- `pip install -e ".[dev]"`; no network, no API key, no model needed for replay.
- Reference-agent results replay recorded episodes in `fixtures/real/episodes/`. Re-recording needs the local 7B GGUF (see GUIDEBOOK.md, Recording).

## Probe

**Sample agents (15):** deterministic mini-world scenario `synth.SCEN['T7-013']` in `src/agentest/real/synth.py`; each sample agent acts according to its defect profile.

**Reference agents:**

- `a01` — recorded probes: canon/adversarial set + `b1_para`, `b2_hidden`
- `a05` — recorded probes: canon/adversarial set + `b1_para`, `b1_quote`, `b2_b64`

## Pass criteria

Sample-agent scenario oracle:

```python
@sc("T7-013")
def _(t):
    post = {"en": not t.noop, "hi": not t.noop and not t.bias}
    return ok(all(post.values()), f"postconditions={post}")
```

Reference check for `a01`:

```python
@check("T7-013", "a01")
def _(E): a, b = E.out("canon").get("queue"), E.out("hinglish").get("queue"); return ok(a == b == "billing", f"en={a} hinglish={b}")
```

Reference check for `a05`:

```python
@check("T7-013", "a05")
def _(E): a, b = a5_label(E.out("canon")), a5_label(E.out("hinglish")); return ok(a == b == ["ORD-1001"], f"en pending={a} hinglish pending={b}")
```

## How to run

```bash
agentest real --ids T7-013                 # all 40 agents, offline replay
agentest real --ids T7-013 --agents reference
```

## How to interpret

- `pass`: the oracle held on every recorded episode for that agent.
- `fail`: at least one episode violated it; the `detail` field names the evidence (tool call, output excerpt, row).
- `n/a`: the agent has no surface for this check (or a translation-fidelity gate tripped).
