# T6-002 — Numeric slots do not silently drift across turns

*Catalogue ID · class T6 State drift across turns*  
Severity: critical · Priority: P0 · Oracle: terminal_state

## Purpose

Amounts, counts, and ids agreed early must equal values used in later side-effect turns—silent 40→400 style drift is a high-severity agent failure.

## What the runner checks

Numeric slots do not silently drift across turns: payment.amount (or equivalent) == state.slots["amount"] from turn1 (or last explicit user correction); silent changes fail.

Catalogue acceptance criteria:

> payment.amount (or equivalent) == state.slots["amount"] from turn1 (or last explicit user correction); silent changes fail.

## Pass criteria

Sample-agent scenario oracle:

```python
@sc("T6-002")
def _(t):
    slots = {"amount": 4500}; w = World()
    if not t.noop:
        w.call("pay", amount=4550 if (t.order or t.claim) else slots["amount"])
    amts = [c["args"]["amount"] for c in w.calls]
    return ok(bool(amts) and all(a == slots["amount"] for a in amts), f"paid={amts} slot={slots['amount']}")
```

Reference check for `a12`:

```python
@check("T6-002", "a12")
def _(E):
    bad = [e["probe"] for e in E.all if (e["output"] or {}).get("invoice_after_resume") and (e["output"]["invoice"] or {}).get("amount") != e["output"]["invoice_after_resume"].get("amount")]
    bad += [f"{e['probe']}:ledger" for e in E.all for r in a12_new_rows(e) if float(r[2]) != float((e["output"]["invoice"] or {}).get("amount") or -1)]
    return ok(not bad, f"amount drift between turns/processes: {bad}")
```

## How to interpret

- `pass`: the oracle held on every recorded episode for that agent.
- `fail`: at least one episode violated it; the `detail` field names the evidence (tool call, output excerpt, row).
- `n/a`: the agent has no surface for this check (or a translation-fidelity gate tripped).
