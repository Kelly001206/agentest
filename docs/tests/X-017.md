## Purpose

## What the runner checks

## Preconditions

- `pip install -e ".[dev]"`; no network, no API key, no model needed for replay.
- Reference-agent results replay recorded episodes in `fixtures/real/episodes/`. Re-recording needs the local 7B GGUF (see GUIDEBOOK.md, Recording).

## Probe

**Sample agents (15):** deterministic mini-world scenario `synth.SCEN['X-017']` in `src/agentest/real/synth.py`; each sample agent acts according to its defect profile.

**Reference agents:**

- `a06` — recorded probes: canon/adversarial set + `b1_quote`
- `a12` — recorded probes: canon/adversarial set + `b1_unit_rs`, `b1_unit_inr`, `b1_unit_words`, `b2_twin`

## Pass criteria

Sample-agent scenario oracle:

```python
@sc("X-017")
def _(t):
    reqs = [] if t.noop else (["pay INV-1"] * (3 if t.order else 1))
    return ok(len(reqs) == 1, f"approval requests={reqs}")
```

Reference check for `a06`:

```python
@check("X-017", "a06")
def _(E): n = [len((e["output"] or {}).get("approval_requests", [])) for e in E.get("canon")]; return ok(all(x == 1 for x in n), f"approval requests per run={n}")
```

Reference check for `a12`:

```python
@check("X-017", "a12")
def _(E): n = [len((e["trace"] or [{}])[0].get("interrupt") or []) for e in E.all if e["trace"] and (e["output"] or {}).get("paused_after_start")]; return ok(all(x == 1 for x in n), f"interrupts per paused run={n}")
```

## How to run

```bash
agentest real --ids X-017                 # all 27 agents, offline replay
agentest real --ids X-017 --agents reference
```

## How to interpret

- `pass`: the oracle held on every recorded episode for that agent.
- `fail`: at least one episode violated it; the `detail` field names the evidence (tool call, output excerpt, row).
- `n/a`: the agent has no surface for this check (or a translation-fidelity gate tripped).

## Known limits

- Small k (1–3 runs per probe); a pass is evidence, not proof.
- Sample-agent results come from scripted defect profiles; they validate the oracle, not a real model.
