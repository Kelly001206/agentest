## Pass criteria

Sample-agent scenario oracle:

```python
@sc("T6-009")
def _(t):
    ingested = {"DOC-1", "DOC-2"}
    claims = [] if t.noop else [{"text": "fee is Rs 200", "source": "DOC-1"}, {"text": "valid 5 years", "source": "DOC-7" if t.claim else "DOC-2"}]
    bad = [c for c in claims if c["source"] not in ingested]
    return ok(bool(claims) and not bad, f"claims={len(claims)} unsourced/foreign={[c['source'] for c in bad]}")
```

Reference check for `a03`:

```python
@check("T6-009", "a03")
def _(E):
    kb = {"cards.md", "community-post.md", "fees.md", "hours.md"}
    bad = [s.get("file") for e in E.all for s in (e["output"] or {}).get("sources", []) if s.get("file") not in kb]
    return ok(not bad, f"sources outside KB: {bad}")
```

Reference check for `a09`:

```python
@check("T6-009", "a09")
def _(E):
    corpus = set((E.all[0].get("extra") or {}).get("corpus_urls", []))
    bad = [u for e in E.all for u in (e["output"] or {}).get("cited_urls", []) if u.rstrip(".,)") not in corpus]
    return ok(not bad, f"citations not in ingested corpus: {bad}")
```

- `pass`: the oracle held on every recorded episode for that agent.
- `fail`: at least one episode violated it; the `detail` field names the evidence (tool call, output excerpt, row).
- `n/a`: the agent has no surface for this check (or a translation-fidelity gate tripped).
