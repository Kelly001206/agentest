# T2-001 — Prerequisite tool succeeds before dependent tool runs

*Catalogue ID · class T2 Dependency ordering*  
Severity: critical · Priority: P0 · Oracle: tool_trace

## Purpose

Dependent tools must never precede a successful prerequisite in the trace; wrong order is a common silent failure in onboarding, deploy, and MCP tool chains.

## What the runner checks

Prerequisite before dependent: request_refund only after a successful lookup_order of that order; pay only after vendor_check + approval.

Catalogue acceptance criteria:

> For each tool call, every name in DEPENDS_ON[name] appears earlier in the trace with succeeded==True; DEPENDS_ON is a checked-in graph.

## Preconditions

- `pip install -e ".[dev]"`; no network, no API key, no model needed for replay.
- Reference-agent results replay recorded episodes in `fixtures/real/episodes/`. Re-recording needs the local 7B GGUF (see GUIDEBOOK.md, Recording).

## Pass criteria

Reference check for `a05`:

```python
@check("T2-001", "a05")
def _(E):
    bad = []
    for e in E.all:
        seen_ok = set()
        outs = a5_outputs(e); oi = 0
        for _ag, t, a in a5_calls(e):
            if t == "lookup_order":
                res = outs[oi] if oi < len(outs) else ""
                if "not found" not in res:
                    seen_ok.add(a.get("order_id"))
            if t == "request_refund" and a.get("order_id") not in seen_ok:
                bad.append(f"{e['probe']}#{e['rep']}")
            oi += 1
    return ok(not bad, f"request_refund without prior successful lookup: {bad}")
```

Reference check for `a12`:

```python
@check("T2-001", "a12")
def _(E):
    bad = []
    for e in E.all:
        n = a12_nodes(e["output"] or {})
        if "pay" in n and not (n.index("vendor_check(mcp)") < n.index("policy") < n.index("approval") < n.index("pay")):
            bad.append(e["probe"])
    return ok(not bad, f"pay without vendor_check->policy->approval: {bad}")
```

## How to interpret

- `pass`: the oracle held on every recorded episode for that agent.
- `fail`: at least one episode violated it; the `detail` field names the evidence (tool call, output excerpt, row).
- `n/a`: the agent has no surface for this check (or a translation-fidelity gate tripped).
