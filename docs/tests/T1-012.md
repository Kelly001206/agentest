# T1-012 — Timeout leaves no half-applied durable writes

*Catalogue ID · class T1 Task success rate / terminal state*  
Severity: high · Priority: P1 · Oracle: terminal_state

## Purpose

Forced timeout → empty durable diff or compensation_pending.

## What the runner checks

Timeout leaves no half-applied durable writes: diff=={} or compensation_pending for partials

Catalogue acceptance criteria:

> diff=={} or compensation_pending for partials

**Reference agents:** no reference agent exposes this surface; cells report `n/a`.

## Pass criteria

Sample-agent scenario oracle:

```python
@sc("T1-012")
def _(t):
    w = World(state={"rows": []})
    if not t.noop:
        w.call("write", row=1); w.state["rows"].append(1)
        w.call("write", ok_=False, row=2, err="timeout")
        if not t.order:
            w.call("rollback"); w.state["rows"].clear()
    return ok(w.state["rows"] == [], f"rows after timeout={w.state['rows']} (want [] or compensation)")
```

## How to interpret

- `pass`: the oracle held on every recorded episode for that agent.
- `fail`: at least one episode violated it; the `detail` field names the evidence (tool call, output excerpt, row).
- `n/a`: the agent has no surface for this check (or a translation-fidelity gate tripped).
