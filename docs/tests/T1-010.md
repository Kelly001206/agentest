# T1-010 — Status field only accepts allowed enum values

*Catalogue ID · class T1 Task success rate / terminal state*  
Severity: medium · Priority: P1 · Oracle: terminal_state

## Purpose

Illegal status strings must not be written.

## What the runner checks

Status field only accepts allowed enum values: ticket.status ∈ frozenset({OPEN,PENDING,CLOSED})

Catalogue acceptance criteria:

> ticket.status ∈ frozenset({OPEN,PENDING,CLOSED})

## Preconditions

- `pip install -e ".[dev]"`; no network, no API key, no model needed for replay.
- Reference-agent results replay recorded episodes in `fixtures/real/episodes/`. Re-recording needs the local 7B GGUF (see GUIDEBOOK.md, Recording).

## Probe

**Sample agents (15):** deterministic mini-world scenario `synth.SCEN['T1-010']` in `src/agentest/real/synth.py`; each sample agent acts according to its defect profile.

**Reference agents:**

- `a01` — recorded probes: canon/adversarial set + `b1_para`, `b2_hidden`
- `a02` — recorded probes: canon/adversarial set + `b1_para`, `b1_unit_inr`, `b1_unit_words`, `b2_hidden`, `b2_json`
- `a12` — recorded probes: canon/adversarial set + `b1_unit_rs`, `b1_unit_inr`, `b1_unit_words`, `b2_twin`

## Pass criteria

Sample-agent scenario oracle:

```python
@sc("T1-010")
def _(t):
    allowed = {"OPEN", "PENDING", "CLOSED"}
    w = World(state={"status": "OPEN"})
    if not t.noop:
        v = "RESOLVED-ISH" if t.claim else "CLOSED"
        w.call("set_status", value=v); w.state["status"] = v
    return ok(w.state["status"] in allowed and not t.noop, f"status={w.state['status']} (allowed {sorted(allowed)}; noop never closes)")
```

## How to interpret

- `pass`: the oracle held on every recorded episode for that agent.
- `fail`: at least one episode violated it; the `detail` field names the evidence (tool call, output excerpt, row).
- `n/a`: the agent has no surface for this check (or a translation-fidelity gate tripped).
