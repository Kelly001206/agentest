# Contributing

1. One Hub ID per PR when possible (`T1-001`, …).
2. PR must show: Hub ID, pack, Pass on golden, Fail on `broken_agent`, CI minutes.
3. Do not renumber T1–T7 IDs.
4. Security-labelled issues are parked until `v0.5.0`.
5. Catalogue changes land on Hugging Face first; then update `catalog/VERSION`.
