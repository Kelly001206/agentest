# Contributing

1. One catalogue ID per PR when possible (`T1-001`, …).
2. PR must show: catalogue ID, pack, Pass on golden, Fail on `broken_agent`, CI minutes.
3. Do not renumber T1–T7 IDs.
4. Security-labelled issues are parked until `v0.5.0`.
5. Catalogue changes land in the catalogue first; then update `catalog/VERSION`.
